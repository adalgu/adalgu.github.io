## 들어가며

맥북의 iPhone 미러링 창을 Claude 데스크탑의 컴퓨터 사용(computer use)으로 조작하면, 미뤄 두던 아이폰 단축어 자동화를 대화하듯 만들 수 있다. 하루 저녁에 자동화 두 개를 완성했다.

단축어 앱은 강력하지만, 작은 화면에서 변수를 고르고 조건문을 끌어 넣는 일이 번거로워 늘 "언젠가 해야지"로 남아 있었다. 이 글은 그 일을 Claude와 나눠서 끝낸 기록이다. 무엇이 자동으로 됐고, 어디서 사람이 손을 대야 했는지 그대로 적었다.

## 준비물과 구성

맥과 아이폰이 같은 Apple 계정이고, 맥에 Claude 데스크탑 앱만 있으면 된다. Claude는 미러링 창을 스크린샷으로 보고 클릭해서 아이폰을 조작한다.

| 구성 요소 | 역할 |
| --- | --- |
| 맥북 + iPhone 미러링 앱 | 아이폰 화면을 맥 창으로 띄움 |
| Claude 데스크탑 — 컴퓨터 사용 | 미러링 창을 보고 탭·스크롤·메뉴 조작 |
| 아이폰 단축어 앱 | 자동화가 실제로 만들어지는 곳 |
| 나(사용자) | 글자 입력, 길게 눌러 끌기, 최종 확인 |

설정 순서:

1. Claude 데스크탑 설정에서 컴퓨터 사용을 켠다(기본값은 꺼져 있다).
2. Claude가 요청하는 앱 접근 권한에서 'iPhone Mirroring'만 허용했다.
3. 기본은 백그라운드 제어라서 그동안 맥을 계속 쓸 수 있다. 필요하면 '화면 넘겨받기(전체 화면 제어)'를 따로 허용한다.
4. 클립보드 쓰기도 별도 권한이다.

## 사례 1: 문자 한 통으로 주차앱 열기

맥미니가 내 iMessage 계정으로 미리 정한 키워드(예: KEYWORD)가 들어간 문자를 보내면, 아이폰이 주차앱 웹페이지를 바로 열게 했다. 같은 계정에서 보낸 문자도 아이폰에는 내 대화방에 '받은 메시지'로 들어오기 때문에 가능한 일이다.

| 항목 | 설정 |
| --- | --- |
| 자동화 종류 | 개인용 자동화 → 메시지 |
| 보낸 사람 | 내 연락처 |
| 메시지 포함 내용 | 미리 정한 키워드 (예: KEYWORD) |
| 실행 방식 | 즉시 실행 |
| 동작 | URL 열기 → 주차앱 웹페이지 |

Claude에게 준 지시에는 단계별 절차와 함께 '하지 말 것'을 분명히 적었다. 메시지를 보내지 말 것, 다른 자동화는 건드리지 말 것, 암호·결제 화면이 나오면 멈출 것, 메뉴 이름이 다르면 추측하지 말고 물어볼 것. 시험 문자를 보내자 주차앱 페이지가 바로 열렸다.

## 사례 2: 차에 타면 시간대에 맞는 내비 켜기

차의 블루투스에 연결되면 원래는 유튜브 뮤직만 틀었다. 여기에 평일 시간대에 따라 목적지를 골라 길안내를 시작하는 조건을 더했다.

| 평일 시간(예시) | 목적지 | 사용한 동작 |
| --- | --- | --- |
| 07:00–09:59 (출근) | 회사 | 카카오내비 회사로 안내 |
| 12:00–12:59 (점심) | 운동 시설 | 네이버지도 내비게이션 회사로 길찾기 |
| 13:00–13:59 (복귀) | 회사 | 카카오내비 회사로 안내 |
| 18:00–20:59 (퇴근) | 집 | 카카오내비 집으로 안내 |

내비 앱들은 단축어에 '집으로', '회사로' 동작만 주고, 임의의 목적지 동작은 없었다. 그래서 점심 목적지는 네이버지도의 '회사'를 점심 목적지(운동 시설)로 등록해 두는 요령을 썼다. 좌표도 별도 단축어도 필요 없다.

완성된 자동화의 동작 순서는 아래와 같다. 조건문을 중첩하지 않고 나란히 두었다. 시간 범위가 겹치지 않아 항상 하나만 참이 되기 때문이다.

```
[유튜브 뮤직 단축어 실행]
[날짜 포맷 지정: 현재 날짜 → E]        → 변수 이름 '요일'
조건문 (일부: 요일 = 토 / 요일 = 일)
   메뉴에서 선택 "집으로 안내할까요"
     집으로 → 카카오내비 집으로 안내
     아니야 → (비움)
   메뉴 종료
   이 단축어 중단
조건문 종료
[날짜 포맷 지정: 현재 날짜 → HHmm]     → 변수 이름 '시각', 유형 숫자
조건문 (시각 700 ~ 959)   → 카카오내비 회사로 안내
조건문 (시각 1200 ~ 1259) → 네이버지도 내비게이션 회사로 길찾기
조건문 (시각 1300 ~ 1359) → 카카오내비 회사로 안내
조건문 (시각 1800 ~ 2059) → 카카오내비 집으로 안내
```

설정하면서 배운 점:

- iOS 한국어에서는 If가 '만약'이 아니라 \*\*'조건문'\*\*이고, '스크립트하기' 안에 있다.
- 조건문의 \*\*'일부'\*\*가 영어의 Any다. 토·일을 한 조건문에 넣을 수 있다.
- 날짜 포맷 결과는 모두 '포맷 지정된 날짜'로 보여서 헷갈린다. **변수 이름을 '요일', '시각'으로 바꾸면** 실수가 없어진다.
- 시각 변수의 유형을 **숫자**로 바꾸면 '다음 범위 사이에 있음' 조건을 쓸 수 있다.

## 부딪힌 문제와 해결

가장 큰 벽은 글자 입력이었다. 미러링 창에는 Claude가 글자를 칠 수 없었고, 나머지 문제는 대부분 돌아갈 길이 있었다.

| 증상 | 원인(추정) | 해결 |
| --- | --- | --- |
| 어떤 글자를 보내도 모두 'a'로 찍힘 | 미러링 창이 합성된 키 입력을 제대로 받지 못함. 백그라운드와 전체 화면 제어 모두 동일 | 글자 입력만 사람이 맡음 |
| 전체 화면 클릭이 'Magnet' 때문에 거부됨 | 창 관리 앱 Magnet의 투명 창이 미러링 창 위에 겹침 | 터미널에서 `killall Magnet`으로 잠시 종료 |
| 편집 메뉴의 '붙여넣기'가 회색 | 미러링 창이 맥 클립보드 붙여넣기를 받지 않음 | 클립보드 우회도 포기, 사람이 입력 |
| 특정 창에서 화면이 안 넘어감 | 앱 보관함 폴더, 변수 줄 등은 끌기가 안 먹힘 | 메뉴 막대의 보기 → Spotlight, 홈 화면으로 우회 |
| 미러링 'Connection Interrupted' | 내가 폰을 직접 만지면 자동으로 끊김 | 폰을 잠그고 내려놓은 뒤 '다시 시도' |
| 홈 화면에서 엉뚱한 앱 실행 | 비슷한 아이콘을 단축어로 오인 | Claude가 바로 취소하고 보고. 앱은 내가 직접 열어 주는 게 빠름 |

특히 첫 줄이 중요하다. 이번 환경에서는 완전 자동화가 아니라 **반자동화**가 현실적인 답이었다.

## 사람과 Claude의 역할 분담

Claude는 누르고 확인하고, 사람은 치고 끌었다. 이렇게 나누자 한 단계가 수십 초면 끝났다.

| Claude가 맡은 일 | 내가 맡은 일 |
| --- | --- |
| 탭, 토글, 메뉴 선택(즉시 실행, 조건 연산자) | 글자 입력(키워드, URL, 숫자, `E`, `HHmm`) |
| 변수 연결(요일 동작의 결과 고르기) | 동작을 길게 눌러 조건문 안으로 끌기 |
| 화면을 보고 값과 구조 검수 | 앱 하나 열기, 연락처 고르기 |
| 다음 단계 안내, 내비 앱이 주는 동작 확인 | 네이버지도 '회사' 주소 바꾸기 같은 앱 밖 작업 |

효과를 본 요령:

- **처음에 '하지 말 것'을 적어 주기.** 메시지 보내기, 다른 설정 변경, 암호 화면을 미리 막아 두면 안심하고 맡길 수 있다.
- **"완료" 한마디로 넘기기.** 내가 입력을 끝내고 완료라고 하면, Claude가 미러링 화면을 다시 찍어 검수하고 다음을 안내했다.
- **검수는 꼭 Claude에게.** 두 번째 날짜 포맷에 현재 날짜 대신 앞 동작의 결과가 들어간 것처럼, 눈으로 놓치기 쉬운 실수를 잡아냈다.
- **폰을 만질 때는 미러링이 끊긴다는 것을 알고 있기.** 폰에서 작업한 뒤에는 스크린샷을 보내거나, 폰을 잠그고 다시 연결하면 된다.

## 더 해 볼 만한 것들

구조가 한 번 잡히면 조건과 동작만 바꿔 끼우면 된다. 이미 넣은 것과 다음 후보를 모아 봤다.

- **목적지 음성 안내 (적용함):** 길안내 전에 '텍스트 말하기'로 "회사로 안내합니다"를 말해 준다.
- **주말에는 물어보기 (적용함):** '메뉴에서 선택'으로 "집으로 안내할까요?"를 띄운다. 주말 저녁에만 묻게 하려면 시각 조건문으로 한 번 더 감싸면 된다. 운전 중 조작은 피하고, 시동 직후 정차 상태에서만 누르는 게 안전하다.
- **위치 조건:** '현재 위치 가져오기' → '거리 가져오기'(집까지 km)로, 집에서 2km 넘게 떨어져 있을 때만 집으로 갈지 묻는다. 위치를 잡는 데 1\~3초가 더 걸린다.
- **아침 브리핑:** 날씨와 오늘 첫 일정을 읽어 준다.
- **퇴근 알림:** 저녁 블록에서 가족에게 "지금 출발"을 보낸다. 처음에는 보내기 전에 확인하게 두는 편이 낫다.
- **차에서 내릴 때:** '블루투스 연결 해제' 자동화로 현재 위치를 메모하거나 주차앱을 연다. 사례 1과 자연스럽게 이어진다.

## 마치며

Claude의 컴퓨터 사용은 아이폰 단축어를 '혼자 끝까지' 만들어 주지는 못했다. 대신 어디를 눌러야 하는지, 무엇을 입력해야 하는지, 제대로 됐는지를 대신 챙겨 주는 동료가 됐다. 귀찮아서 미루던 자동화가 있다면, 맥에서 iPhone 미러링을 띄우고 하고 싶은 일과 하지 말 것을 적어 주는 것부터 시작해 보자.
